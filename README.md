# საეკლესიო კალენდარი — ვებ-ვერსია (Next.js)

Android და iOS აპლიკაციების ვებ-ვერსია. მთელი კალენდარი ბრაუზერში მუშაობს — სერვერი არ სჭირდება.

- **Next.js 16** (App Router, TypeScript)
- **Tailwind CSS 4**
- **სტატიკური ექსპორტი** (`output: "export"`) — შედეგი `out/` საქაღალდეა, რომელიც ნებისმიერ ჰოსტინგზე იდება.

## გაშვება

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # სტატიკური საიტი ./out საქაღალდეში
```

## განთავსება

`npm run build`-ის შემდეგ `out/` საქაღალდე აიტვირთება:

- **Cloudflare Pages** — Build command: `npm run build`, Output directory: `out`
- **GitHub Pages / Netlify / ნებისმიერი სტატიკური სერვერი** — უბრალოდ ატვირთე `out/`-ის შიგთავსი

## სტრუქტურა

```
src/

│   ├── lives/           წმინდანთა ცხოვრება
│   ├── saints/          სახელთა საძიებელი
│   ├── glossary/        მცირე განმარტებანი
│   └── about/           კონტაქტი
├── components/          UI კომპონენტები (Providers, AppHeader, DayScreen, MonthCalendar…)
├── lib/calendar.ts      კალენდრის მთელი ლოგიკა
└── fonts/               ქართული ფონტები (next/font/local)

```

## მონაცემები

`public/data/` იგივე ფაილებია, რაც iOS ვერსიაში — ისინი ორიგინალი Java კლასების (Moving, Name,
Marxva, Troparions…) გაშვებით არის აგებული 1897–2103 წლებისთვის:

| ფაილი | შიგთავსი |
|---|---|
| `calendar_data.json` | მოძრავი დღესასწაულები, ყოველი დღის ხსენებები, ტროპარები, წლიური მაჩვენებლები |
| `fasting.bin` | ყოველი დღის მარხვა (1 ბაიტი დღეზე) |
| `day_images.bin` | ყოველი დღის ხატი |
| `day_meta.json` | ხატებისა და მარხვების სახელები |
| `life_index.json` | წმინდანთა ცხოვრების სათაურები თარიღების მიხედვით |
| `saints.json` | სახელთა საძიებელი (4443 ჩანაწერი) |

TypeScript ლოგიკა შედარებულია ორიგინალ Java კოდის გამოტანასთან **1899–2101 წლების ყველა დღეზე
(74 144 დღე)** — ხსენებები, ხატი, მარხვა, თევზი და ტროპარები ყველგან ემთხვევა.

## დიზაინი

აპლიკაციის სტილი შენარჩუნებულია (ქაღალდის ფონი, ოქროსფერი აქცენტი, ქართული ფონტები), მაგრამ
განლაგება ვებისთვისაა გადაკეთებული:

- ორსვეტიანი განლაგება დიდ ეკრანზე (მარცხნივ დღე და კალენდარი, მარჯვნივ ხსენებები), ერთსვეტიანი მობილურზე;
- მთვარის კალენდარი მარხვის ფერადი ნიშნებით;
- პარამეტრები ზედა პანელში: ღია/ბნელი თემა, ფონტი, ტექსტის ზომა, ფონის სურათი (ინახება ბრაუზერში);
- კლავიატურა: `←` `→` დღეების გადასვლა, `T` — დღევანდელი დღე; მობილურზე მარცხნივ/მარჯვნივ გადაფურცვლა;
- ბმული კონკრეტულ დღეზე: `/?date=2026-04-12`.
